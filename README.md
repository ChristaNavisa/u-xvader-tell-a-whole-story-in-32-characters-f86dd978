One Wi-Fi network name, exactly 32 characters, that tells a whole story:
a breakup, an ex, and the pettiest theft of all — the router.

Run `node main.ts` and it writes the name to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
